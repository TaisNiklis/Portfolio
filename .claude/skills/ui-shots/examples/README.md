# Reference shots

The original reference images behind the presets, named `<preset>-<n>.<ext>`. They are for
looking: the skill reads `references/library.md` to choose a style and opens these only to
compare a render with the original.

To add references, either attach them to a chat message with the skill ("ось ще приклади,
мобілка"), or upload them here through GitHub (Add file → Upload files) as
`new-<anything>.png` and ask Claude to turn them into presets.

The first batch (sections and the first mobile overview) and the web, dashboard and table
batches were described from chat, but their files weren't saved. Upload them here under the
preset names from `references/library.md` if you want them kept.

## Case family: lavender (the user's own images, HR-platform case)
- `tablet-float-1.png`, `tablet-float-2.png`: a whole screen in a dark tablet bezel.
- `annotated-fragment-1.png`: a checklist fragment with integration cards and dashed connectors.
- `fragment-collage-1.png`: payout-method fragments placed by hand.
- `focus-closeup-1.png`: a dropdown kept sharp, the rest blurred.
- `photo-mockup-1.png`: hands holding a tablet (made in Figma; reference only).
Logos are blurred for NDA.
