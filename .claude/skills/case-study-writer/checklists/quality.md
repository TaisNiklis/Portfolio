# Quality checklist

Run against every draft. Report each item as ✅ / ⚠️ (with a fix) / ❌.

## Skim test (30 seconds)
- [ ] The title states an outcome, not a project name
- [ ] The header has 2–3 metrics, each with a source
- [ ] The TL;DR alone tells problem → action → result
- [ ] Reading only the headings and bold phrases gives the story

## Seniority test
- [ ] "I" appears in decisions, not only in tasks
- [ ] At least 2 alternatives and why they were rejected
- [ ] At least 1 trade-off or constraint handled
- [ ] At least 1 moment of influence (client, PM or devs)
- [ ] Business goal and user goal both named

## Evidence test
- [ ] Every number has a source, and none is invented
- [ ] Every insight has evidence
- [ ] Every image has a caption with *what* and *why*
- [ ] Before/after is present if it's a redesign

## Craft
- [ ] 800–1500 words
- [ ] 8–15 image slots
- [ ] No banned filler from `references/rules.md`
- [ ] NDA handled (client name, data, `nda` flag)
- [ ] Frontmatter complete: title, slug, summary, product, role, team, timeline, platform,
      tags, metrics, cover, nda, order
- [ ] The AI-in-process callout is present
- [ ] Open `[TODO]`s are listed for the user
