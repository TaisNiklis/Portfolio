# Raw material checklist / Що зібрати для кейсу

Send this to the user before a case if material is thin.

- [ ] **Бриф / вимоги**: що просив клієнт чи бізнес, обмеження, терміни
- [ ] **Команда**: хто був (PM, розробники, дизайнери, клієнт), твоя зона відповідальності
- [ ] **Проблема**: як дізнались, що є проблема (дані, скарги, аудит)
- [ ] **Дослідження**: нотатки інтерв'ю, аудиту, аналітики, ключові цитати
- [ ] **Артефакти**: флоу, матриці ролей, мапи сутностей і статусів, вайрфрейми
- [ ] **Варіанти**: що ще розглядали і чому відмовились
- [ ] **Суперечки**: де переконувала клієнта чи команду, і як саме
- [ ] **Фінальні екрани**: посилання на Figma або експорт, before/after
- [ ] **Передача в розробку**: як передавали, що з дизайн-системи
- [ ] **Метрики** або непрямі показники + джерело
- [ ] **Фідбек**: клієнта, команди або користувачів (цитата)
- [ ] **Висновки**: що зробила б інакше
- [ ] **AI у процесі**: де допомагав Claude / Figma AI
- [ ] **NDA**: що не можна показувати
