# Rules

## Metrics
- Prefer real numbers: adoption, conversion, task time, support tickets, retention, dev time, budget.
- No hard numbers? Use proxy evidence:
  - iterations until client sign-off;
  - developer onboarding or handoff time;
  - UX issues found and fixed in an audit;
  - a client or user quote.
- **Always state the source**: "client analytics", "internal estimate", "usability test, n=6".
- Never round up, combine numbers or extrapolate without saying so. If the user is unsure,
  write "≈" and the source.
- If a number is missing, write `[TODO: metric — e.g. % of active users who used AI chat
  before/after]`. Don't make one up.

## NDA
- Replace the client name with a description: "a B2B SaaS for logistics with 200+ enterprise clients".
- Use relative numbers (%, ×) instead of absolute ones (revenue, user counts).
- Screens: blur or replace real data, names and logos. Note that in the image shot list.
- Set `nda: true` in the frontmatter and add a one-line note in Context.

## Visuals
- No galleries. Every image has a caption: what it is and why it matters.
- Show thinking artifacts: role matrix, status map, user flow, audit notes, rejected options.
- Use before/after for any redesign.
- Keep one mockup and background style across all cases.
- Make it mobile-readable: no small text inside images. Crop key details into separate images.
- Aim for 8–15 images per case.

## Writing
- Write in English with short sentences and active verbs: *led, proposed, reduced, aligned,
  convinced, cut, shipped*.
- Use "I" for her own decisions and "we" for team outcomes, never one to blur the other.
- Bold one key phrase per section so a skim gives the story.
- Name concrete things: screens, roles, numbers, timeframes.
- Target B2 to C1 readability: no idioms that need native-level English to explain in an
  interview.

### Banned filler (replace with specifics)
user-centric · seamless · intuitive (without evidence) · delightful · cutting-edge · robust ·
leveraged synergies · pixel-perfect · "I was responsible for design" · "we made it better" ·
"improved UX" (without saying what and by how much)
